Syntax guide
u(t) step(t)unit step
r(t) ramp(t)unit ramp
delta(t) δ(t)impulse (δ[n] for discrete)
rect(t)1 for |t| < 1/2
tri(t)triangle, width 2, peak 1
sinc(t)sin(πt)/(πt)
sin cos tan expalso abs sgn sqrt ln
e^{-2t}, 2^tpowers; e and pi are constants
2u(t-1)implicit multiplication works
x(2t-1)use another plot by its name
u[n], x[n-2]square brackets for discrete

LaTeX style input also works: \delta(t-1), \frac{1}{2}, e^{-t}, \sin(2\pi t).

Custom ticks: list values with commas, like -1, 1, 2pi. Use value=label for symbolic labels, like 2=T, 4=2T.

Impulses and jumps are placed exactly, not sampled. Impulse arguments must be of the form at+b.
